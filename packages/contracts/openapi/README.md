# Active Fastify API contract

`openapi.yaml` documents only implemented Fastify HTTP endpoints: liveness and readiness.

The original extensive Happy Birthday Diana API draft and reconciliation notes were moved to the external legacy archive. Authentication, collaboration, personal memory, media, and publication operations are **not currently implemented** in Fastify. Reintroduce them only with authorization, idempotency, PostgreSQL concurrency and response-contract equivalence.
